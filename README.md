# آوا — مرکز فرماندهی آموزشگاه موسیقی

پنل مدیریت یکپارچهٔ «آکادمی موسیقی آوا» — تجربه‌ای فارسی، راست‌به‌چپ و سینمایی برای ادارهٔ روزانهٔ یک آموزشگاه موسیقی حرفه‌ای.

> «یک مرکز فرماندهی مدرن برای ادارهٔ یک آکادمی موسیقی»

## اجرا

```bash
npm install
npm run dev      # توسعه
npm run build    # خروجی تک‌فایل در dist/
npm run typecheck
```

## ساختار

```
src/
├── components/
│   ├── ds/            # سیستم طراحی: primitives · patterns · blocks · states
│   ├── hero/          # قهرمان داشبورد + موج نبض (canvas)
│   ├── layout/        # نوار کناری، نوار بالا، ناوبری موبایل
│   ├── overlays/      # فرمان‌پالت (⌘K) · اکشن‌شیت · توست
│   └── panels/        # نشانه‌ها · نیازمند توجه · هوش آموزشگاه · تحلیل
├── context/           # AppContext — مسیریابی + سیستم تم
├── data/              # دادهٔ نمایشی، جدا از کامپوننت‌ها
├── lib/               # قالب‌بندی اعداد/زمان + دانش تم (theme)
└── views/             # ۱۲ بخش محصول + ویو طراحی
```

## زبان طراحی

- **تیرهٔ کنسرواتوار** (پیش‌فرض) و **شیشه‌ای** (گزینهٔ ثانویه) — از تنظیمات → ظاهر.
- **لهجهٔ کنترل‌شده**: طلایی صحنه، کهربای ساز، بنفش رزونانس — فقط سه گزینه، نه رنگ‌های پراکنده.
- همهٔ اجزا از توکن‌های معنایی (`gold-*` → متغیر لهجه، `ok/warn/danger/info/violet` ثابت) تغذیه می‌شوند؛ رنگ سخت‌کد در صفحات نیست.
- تراکم (راحت/فشرده) و حرکت (روشن/خاموش) از همین سیستم اعمال و در `localStorage` ذخیره می‌شوند.
- حرکت: ریتم بر پایهٔ ♩ ۱۲۰bpm؛ `prefers-reduced-motion` و تنظیم «حرکت» هر دو رعایت می‌شوند.

## بخش‌های محصول

داشبورد (مرکز فرماندهی) · هنرجویان · مدرسین · کلاس‌ها · برنامه‌ریزی · حضور و غیاب · مالی · گزارش‌ها · پیام‌ها · کتابخانه · تنظیمات · سیستم طراحی.

- **هوش آموزشگاه** یک الگوی محصول/UX است (سیگنال → شواهد → بینش → اقدام) با دادهٔ نمایشی — ادعای هوش مصنوعی واقعی ندارد.
- **دادهٔ نمایشی** در مالی و گزارش‌ها صریحاً برچسب خورده است و ساختار داده‌ها برای جایگزینی با بک‌اند واقعی آماده است.

## نقشهٔ راه

- اتصال دادهٔ واقعی (هنرجویان، کلاس‌ها، مالی)
- پنل مدرس و اپلیکیشن هنرجو — با اشتراک همین مفاهیم دامنه
- لایهٔ هوش واقعی روی همین ساختار سیگنال/شواهد/بینش
