# Private SaaS. Nothing here is public.
#
# READ THIS BEFORE TRUSTING IT:
#
# robots.txt is a REQUEST, not a control. It is a plain-text file that anyone
# can read, and a hostile crawler simply ignores it. Several crawlers listed
# below (Bytespider is the documented example) are reported to crawl straight
# through a Disallow. Perplexity-User and some user-triggered fetchers state
# outright that they bypass robots.txt.
#
# So this file exists for ONE reason: to remove any excuse from crawlers that
# do behave. The controls that actually keep this panel out of search engines
# and AI datasets are, in order of strength:
#
#   1. Authentication — every byte of real data sits behind login.
#   2. `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet` sent as an HTTP
#      HEADER on every response (see deploy/ for nginx and Caddy configs).
#      A header cannot be ignored the way this file can.
#   3. Not publishing the hostname anywhere — no sitemap, no backlinks, no
#      public DNS records beyond what TLS requires.
#   4. Network-level blocking (WAF / Cloudflare bot rules) for the user agents
#      below, which enforces rather than asks.
#
# A wildcard Disallow is intentionally FIRST so that any crawler not named
# below is still refused.
# ---------------------------------------------------------------------------
